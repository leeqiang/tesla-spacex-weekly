## 1. OpenCodeReview（代码审查 CLI / Skill）

- **用途**：阿里开源的 AI 代码审查工具：读取 Git diff（也可用 `ocr scan` 扫整文件），给出带行号的意见。可用自带审查流水线（需单独配置模型服务），或「委托模式」让当前编程 Agent 按它的选文件、规则和报告格式来审。需要 **Git >= 2.41**；支持 Windows / macOS / Linux。许可证为 Apache-2.0。不能替代测试和人工验收。
- **安装 / 使用**（README）：
  - 推荐在要审查的项目里执行：`npx skills add alibaba/open-code-review`，按安装器选择 Skill 和宿主。没有单独的 OCR 模型密钥时，README 建议先用委托模式（`open-code-review-delegate`）。
  - CLI：`npm install -g @alibaba-group/open-code-review`，之后可用 `ocr`。原生模式需先 `ocr config provider` 和 `ocr config model`。委托模式示例：`ocr delegate preview`。
  - 其他安装方式（安装脚本、Release 二进制、从源码构建）以及 Claude Code / Codex 插件命令，见 [官方安装文档](https://open-codereview.ai/docs/installation) 和仓库 `plugins/open-code-review/README.md`。
- **出处**：[alibaba/open-code-review](https://github.com/alibaba/open-code-review) · [官网文档](https://open-codereview.ai/docs) · [来源帖](https://x.com/Gorden_Sun/status/2121934388363768062)
- **场景备注**：适合评估是否加入 3C / Codex 的交付审查。汇总 11/15 首次推荐。未安装实测。审查意见会发给所配置的模型服务，敏感代码慎用。

## 2. Filmera MCP / Skill

- **🏷️ 向未来**
- **用途**：把分镜、生成镜头、特效、时间线和导出做成 Agent 可调用的 MCP 工具，并配有规划镜头、写提示词的 Skill。官方文档写明支持 Seedance 2.5 等模型（最高到 4K 的说法以当前模型目录为准）。生成、重拍、配音和放大会消耗 Filmera 积分；创建和整理节点不收费。11/15 汇总首次提到，11/20 补充了 Skill、积分和「先用更快的模型试提示词」的用法，属同一条目的实质补充，本期只收录一次。
- **安装 / 使用**（[官方 MCP 文档](https://www.filmera.ai/docs/mcp) / [SKILL.md](https://www.filmera.ai/skills/filmera/SKILL.md)）：
  - MCP 端点：`https://www.filmera.ai/api/mcp`（Streamable HTTP）。用连接器 / 远程 MCP 接入后，以 **OAuth** 登录；**API Key 会被 MCP 拒绝**，不要在配置里加 `Authorization` 头。REST 自动化仍可用账号里的 API Key。
  - Claude Code 插件：`/plugin marketplace add filmera-ai/filmera-plugins`，再 `/plugin install filmera@filmera`。也可只加服务器：`claude mcp add --transport http filmera https://www.filmera.ai/api/mcp`。首次调用会打开浏览器登录，之后可用 `/mcp` 重新登录。
  - Cursor：可在 Filmera 工作室里用「Add to Cursor」；或把 `{"mcpServers":{"filmera":{"url":"https://www.filmera.ai/api/mcp"}}}` 写入 `~/.cursor/mcp.json`（不要加 headers）。插件仓库写明 Cursor Marketplace 条目仍在审核中。
  - 其他支持 Streamable HTTP 和 OAuth 2.1 的客户端也可接入；只能发固定 API Key 头的客户端连不了 MCP，可改用 REST。Claude、ChatGPT、Gemini、Grok 的点击接入步骤见官方文档。
  - 默认会在对话里先报价、等你同意再生成，但官方写明这不是硬锁（依赖 Agent 如实转述）；硬上限需在设置里给该 Agent 加消费封顶。
- **出处**：[Filmera MCP 文档](https://www.filmera.ai/docs/mcp) · [SKILL.md](https://www.filmera.ai/skills/filmera/SKILL.md) · [filmera-ai/filmera-plugins](https://github.com/filmera-ai/filmera-plugins) · [11/20 来源帖](https://x.com/EHuanglu/status/2123660876624589141)
- **场景备注**：向未来课程片、产品演示可先低成本试镜头再出成片。素材和生成会经过 Filmera 云端，注意授权和积分消耗。未安装实测。

## 8. Punchcutter（字体工坊 Skill / MCP）

- **用途**：在 Claude、ChatGPT、Codex 等里按描述或手写照片生成可安装的英文字体家族（可变字体、字距、OpenType，并附 Studio 预览页）。需要 **Python 3.10+**。代码为 MIT；你做出的字体版权归你，可自选授权。
- **安装 / 使用**（README）：

- **出处**：[byrishi/punchcutter](https://github.com/byrishi/punchcutter) · [文档](https://byrishi.github.io/punchcutter/)
- **场景备注**：README 写明目前只支持拉丁字母（Basic Latin、Latin-1、Latin Extended-A），**暂无中文**，对向未来中文课件的直接价值有限，更适合英文品牌实验。默认有匿名用量统计，可用 `punchcutter telemetry off` 或 `DO_NOT_TRACK=1` 关闭。未安装实测。不要用来仿制商业字体或商标。

## 12. Open Artifact（原 baoyu-design；实质更新）

- **🏷️ 向未来**
- **用途**：宝玉把原来的 baoyu-design 重建为开源、不绑定特定模型的本地工件编辑器：让 Cursor、Codex、Claude Code 等在本机生成可打开、编辑、批注和导出的幻灯片、UI 设计、设计系统、白板、表格、数据看板、文档和短片。旧地址 [JimLiu/baoyu-design](https://github.com/JimLiu/baoyu-design) 会 301 到本仓库。产物是普通文件夹，由本机守护进程打开编辑页，再把批注送回 Agent 会话。官方强调默认在本机运行，不强制账号、也不绑定某一家模型。许可证为 Apache-2.0。这与早期「一条 `npx skills add JimLiu/baoyu-design` 即用」的安装方式不同，属于实质更新，故再次收录。
- **安装 / 使用**（README / 插件说明；需 **Node.js 22.18+**）：
  - 推荐：从 [Releases](https://github.com/JimLiu/open-artifact/releases) 下载 `open-artifact-plugins.zip`（核验时最新为 v0.13.0），解压到固定目录。
  - Claude Code：`claude plugin marketplace add "/path/to/open-artifact-plugins"`，再 `claude plugin install open-artifact@open-artifact`。
  - Codex：`codex plugin marketplace add "/path/to/open-artifact-plugins"`，再在 `/plugins` 里安装 Open Artifact，或 `codex plugin add open-artifact@open-artifact`。钩子需在 `/hooks` 中批准后才会运行。
  - Cursor：把解压后的 `cursor/` 目录拷到 `~/.cursor/plugins/local/open-artifact`，再执行 **Developer: Reload Window**。
  - 其他宿主（Copilot、Antigravity、ChatGPT、DeepSeek Harness 等）见各插件目录说明。装好后可试：`/open-artifact slides a 6-slide pitch for this repo`。
- **出处**：[JimLiu/open-artifact](https://github.com/JimLiu/open-artifact) · [Releases](https://github.com/JimLiu/open-artifact/releases)
