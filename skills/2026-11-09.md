## 1. video-use

- **🏷️ 向未来**
- **用途**：browser-use 出品的开源视频剪辑 Skill：把素材丢进文件夹，用 Claude Code / Codex 等 Agent 对话剪出 `final.mp4`（去填充词与静音、调色、烧字幕、动画叠层、自检渲染结果）。转写依赖 ElevenLabs Scribe（需 API key）；本地还需 ffmpeg。
- **安装 / 使用**（README / install.md）：把下面提示贴进 Agent，或按手动步骤：
  - 提示安装：`Set up https://github.com/browser-use/video-use for me.`（Agent 会先读 `install.md`，装依赖、注册 Skill，再向你要 ElevenLabs key。）
  - 手动：`git clone https://github.com/browser-use/video-use ~/Developer/video-use` → `cd ~/Developer/video-use && uv sync`（或 `pip install -e .`）→ 安装 ffmpeg → 把仓库 symlink 到 `~/.claude/skills/video-use` 或 `~/.codex/skills/video-use` → 在仓库根配置 `.env` 里的 `ELEVENLABS_API_KEY`。
  - 用法：`cd` 到素材目录启动 Agent，说「edit these into a launch video」；成品在 `<videos_dir>/edit/`。
- **出处**：[browser-use/video-use](https://github.com/browser-use/video-use) · [levelsio 相关案例](https://x.com/levelsio/status/2116959423117857026)
- **场景备注**：向未来课程 / 招生宣传片粗剪；未实测转写与渲染。勿照抄未核验的星数宣传。

## 2. Motion Prompt

- **🏷️ 向未来**
- **用途**：动效 / 运镜 / UI / 落地页效果的「名字库」：192 个带动图样例的名称 + 一句含义 + 示例提示词；装 Skill 后可打开图库点选，再把选中项发给 Agent 套进你的视频或站点。需 Node.js 18+。
- **安装 / 使用**（README）：`npx skills add showheyohtaki/motion-prompt`；也可 Claude Code：`/plugin marketplace add showheyohtaki/motion-prompt` 再 `/plugin install motion-prompt@motion-prompt`。装好后说「Open the motion-prompt library」，或按编号如「use #012 and #045」。不装 Skill 也可直接打开 [图库](https://showheyohtaki.github.io/motion-prompt/) 查名字写进提示词。
- **出处**：[showheyohtaki/motion-prompt](https://github.com/showheyohtaki/motion-prompt)
- **场景备注**：向未来课件动效、产品演示运镜用语；不要写成「把文件丢进 AGENTS.md 就算装完」。

## 5. Visa VVAH（工具流水线，不是单一 Skill）

- **用途**：Visa 开源的 Agent 安全扫描流水线（Discover → Remediate → Validate）：发现、对抗式验证、修复建议 / 改代码、独立评审。输出 Markdown + SARIF。Python ≥ 3.11。**发现与修复都是 LLM 候选，不能替代人工安全评审。**
- **安装 / 使用**（README）：
  - `git clone https://github.com/visa/visa-vulnerability-agentic-harness`
  - `cd visa-vulnerability-agentic-harness`
  - `pip install .          # 或 uv sync；建议在虚拟环境内`
  - `cp .env.example .env   # 配置模型供应商凭证`
  - `vvaharness setup`
  - `vvaharness estimate --repo /path/to/your/repo`
  - `vvaharness scan --repo /path/to/your/repo --stop-after s9   # 只检测、不改代码`
- **安全注意**：扫描会把源码片段发给你配置的模型供应商；只扫你有权测试的仓库，隔离环境运行。S10 会改目标源码（`sdk`/`full` 或 `--remediate`）；用 `--stop-after s9` 可跳过。Exploit verification 会向本机目标发真实流量，默认关闭。
- **出处**：[visa/visa-vulnerability-agentic-harness](https://github.com/visa/visa-vulnerability-agentic-harness)
- **场景备注**：授权仓库的 Agent 驱动安全检查；不是「一个 Skill 装完即用」。安装参数以 README 为准，勿沿用未核实的旧 pip / stop-after 写法。

## 6. XcodeBuildMCP（现名 MobileBuildMCP）

- **用途**：给 Agent 用的 iOS / macOS 构建与测试 MCP + CLI（模拟器构建、测试等）。仓库已迁到 Sentry：`cameroncooke/XcodeBuildMCP` 重定向到 [getsentry/MobileBuildMCP](https://github.com/getsentry/MobileBuildMCP)；npm 包名 `mobilebuildmcp`。需 **macOS 14.5+、Xcode 16.x+**（Homebrew 安装可不另装 Node；npm 需 Node 18+）。
- **安装 / 使用**（README + 官方 clients 文档）：
  - Homebrew：`brew tap getsentry/xcodebuildmcp && brew install mobilebuildmcp`
  - npm：`npm install -g mobilebuildmcp@latest`；或按需 `npx -y mobilebuildmcp@latest mcp`
  - Cursor 项目级 `.cursor/mcp.json` 示例：`{"mcpServers":{"MobileBuildMCP":{"command":"npx","args":["-y","mobilebuildmcp@latest","mcp"]}}}`
  - Skills：`mobilebuildmcp init` 或 `npx -y mobilebuildmcp@latest init`
- **出处**：[getsentry/MobileBuildMCP](https://github.com/getsentry/MobileBuildMCP)（原链接仍可用：[cameroncooke/XcodeBuildMCP](https://github.com/cameroncooke/XcodeBuildMCP)）· [gregisenberg 推荐](https://x.com/gregisenberg/status/2119229734563271124)
- **场景备注**：只在 Mac + Xcode 环境有意义；包名以 README 的 `mobilebuildmcp` 为准，勿写过时的 `xcodebuildmcp` 命令。

## 7. ios-simulator-mcp

- **用途**：iOS 模拟器 MCP：点击、滑动、输入、读无障碍树、截图、录屏、装 / 启 App、深链等。需 **Mac + Xcode + 模拟器**，以及 Facebook IDB（`idb_companion` + `fb-idb`）；Node.js 20+。
- **安装 / 使用**（README）：Cursor `~/.cursor/mcp.json`：`{"mcpServers":{"ios-simulator":{"command":"npx","args":["-y","ios-simulator-mcp"]}}}`。Claude Code：`claude mcp add ios-simulator npx ios-simulator-mcp`。请更新到 **v1.3.3+**（更早版本有命令注入问题，见仓库 SECURITY.md）。
- **出处**：[joshuayoes/ios-simulator-mcp](https://github.com/joshuayoes/ios-simulator-mcp)
- **场景备注**：与 MobileBuildMCP 互补——一个偏构建测试，一个偏模拟器 UI 操作。

## 8. 补充候选（非当晚例行汇总）：agent-desktop

- **用途**：Vercel Labs 的桌面操控工具（Apache-2.0）：通过系统无障碍树读写控件（JSON + ref），提供 CLI 与 `agent-desktop mcp`（stdio）。**不是**完整 Agent 框架 / 沙箱；循环与模型在你自己的 Agent 里。npm 当前为 **v1.2.0**。默认无头操作（不抢焦点）；`--headed` 才走物理输入。平台各有限制；缺无障碍信息的自绘控件可能不可读。动作后应再 `snapshot` 复读状态验收。
- **安装 / 使用**（README / npm）：
  - `npm install -g agent-desktop`
  - `agent-desktop status`
  - `agent-desktop permissions --guide   # macOS 辅助功能授权引导`
  - `npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop`
  - MCP 配置示例：`{"mcpServers":{"agent-desktop":{"command":"agent-desktop","args":["mcp"]}}}`
- **出处**：[vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop) · [npm agent-desktop](https://www.npmjs.com/package/agent-desktop) · [来源帖](https://x.com/Pluvio9yte/status/2119080693233754506)
- **场景备注**：适合做 Codex / Cursor Bot 的桌面适配层；未安装实测。快照与剪贴板可能含隐私内容，勿公开上传。
