**说明**：汇集本周「X 创意想法每日汇总」里「值得试的 AI Skill」条目，便于收藏与安装。安装命令以汇总原文为准；链接指向官方仓库或介绍页。带「🏷️ 向未来」标签的条目适合招生物料、课件、落地页、宣传片等 K-12 AI 教培场景。

## 1. baoyu-design

- **🏷️ 向未来**
- **用途**：宝玉出品、类 Claude Design 的本地 Skill，可做 UI 原型、落地页、可编辑幻灯片、设计系统与仪表盘，输出单文件 HTML；v2.1 支持页内批注，最新版加入局域网分享。需 Node 20+，支持 Cursor 与 Codex。
- **安装 / 使用**：`npx skills add JimLiu/baoyu-design --agent cursor`；Codex 把 agent 换成 `codex`；加 `-g` 全局安装。
- **出处**：[JimLiu/baoyu-design](https://github.com/JimLiu/baoyu-design) · [宝玉推荐 1](https://x.com/dotey/status/2116060639533969759) · [宝玉推荐 2](https://x.com/dotey/status/2116623097839149231)
- **场景备注**：10/30–11/1 连续被推荐。向未来招生落地页、课件幻灯片、课程产品原型沟通；局域网分享便于团队现场看稿。

## 2. guizang-ppt-skill

- **🏷️ 向未来**
- **用途**：歸藏出品，杂志风单文件 HTML 幻灯片；支持演讲者模式，WebGL 背景回归，性能更好。
- **安装 / 使用**：`npx skills add https://github.com/op7418/guizang-ppt-skill --skill guizang-ppt-skill`
- **出处**：[op7418/guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill)
- **场景备注**：向未来课件、招生宣讲 deck、家长会演示。

## 3. Elephant-Goldfish Model

- **用途**：Google 开源的评审流程：全上下文 AI（大象）起草设计，零上下文 AI（金鱼）只看文档做批评，人来拍板；适合功能方案评审。
- **安装 / 使用**：`codex plugin marketplace add google/elephant-goldfish-model`，再 `codex plugin add egm@egm`。
- **出处**：[google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model) · [Gorden Sun 推荐](https://x.com/Gorden_Sun/status/2116725923617866215)
- **场景备注**：技术方案 / 产品需求评审，检验文档本身是否自洽。

## 4. swyx/skills（babysit-runs）

- **用途**：babysit-runs 用低强度推理 + 自审循环，在大批量 Agent 任务上控制成本。
- **安装 / 使用**：按仓库 SKILL.md 放入 Cursor / Codex 的 skills 目录。
- **出处**：[swyxio/skills](https://github.com/swyxio/skills) · [swyx 介绍](https://x.com/swyx/status/2116642586387730593)
- **场景备注**：批量数据处理、批量内容生成等长跑 Agent 任务。
