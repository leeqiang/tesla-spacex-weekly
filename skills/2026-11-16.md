## 1. Capwise（灵录；工具，不是 Skill）

- **🏷️ 向未来**
- **用途**：向阳乔木维护的开源 Mac 录屏与剪辑工作台（基于 Cap）：屏幕 / 摄像头录制、时间线编辑、点击处自动放大、双语字幕、配音与封面，可选 AI 助手（方案先审阅再应用）。基础录制与编辑不需要 Cap 云账号；可选 AI 需自行配置模型或本机 ACP 助手。当前发布包支持 **macOS 13.3+、Apple Silicon**，经过 Developer ID 签名与 Apple 公证。Intel / Windows / Linux 发布包尚未经本项目验证。许可证以仓库 LICENSE 为准（主要代码 AGPLv3）。
- **安装 / 使用**（README）：
  - 下载 [Capwise.dmg](https://github.com/joeseesun/capwise/releases/latest/download/Capwise.dmg)，拖到 Applications，按引导授权屏幕录制（需要人声或摄像头时再授相应权限）。
  - 官网与演示工程：[capwise.qiaomu.ai](https://capwise.qiaomu.ai/)
  - 从源码构建见仓库桌面开发文档，不等于已公证的分发包。
- **出处**：[joeseesun/capwise](https://github.com/joeseesun/capwise)
- **场景备注**：向未来课程演示、商旅产品演示录屏。汇总提到「命令行调用」，当前 README 未写独立 CLI 安装命令，本期未核实。未安装实测。请勿上传 API Key 或未经处理的私人录屏。

## 2. billion-context（上下文压缩代理，不是 Skill）

- **用途**：加在 Agent 与模型 API 之间的上下文压缩代理（安装后命令为 `bili`）：把较早对话折成可按需还原的摘要，以便长会话少占窗口。会经手模型请求和上下文，只建议先在不敏感的项目里试。仓库自称的节省幅度、压缩质量与「可还原」效果本期未独立核实，不要照抄宣传数字。
- **安装 / 使用**（README）：
  - Linux / macOS 推荐用户目录安装（避免 sudo）：`npm install -g billion-context --prefix=~/.local`。`bili` 会装到 `~/.local/bin`；若不在 PATH，把该目录加入 PATH。nvm 或 Homebrew Node 且默认前缀已属当前用户时，可用 `npm install -g billion-context`。Windows 可用同样的全局安装（默认前缀通常可写）。
  - 常见用法三选一：原生插件 `bili plugin install <client>`；启动器 `bili <client>`（同时拉起代理和客户端）；或把客户端 baseURL 加上代理前缀 `/bili/`。
  - Claude Code：`bili claude` 或 `bili plugin install claude`。也可 `/plugin marketplace add ranxianglei/billion-context`，再 `/plugin install billion-context@billion-context`，然后跑 `/billion-context:bili-setup`。
  - Codex：`bili codex`，或 `bili plugin install codex`（README 注明：MCP-shell 配套需先启动 bili，该方式不转发 Codex 自身流量）。
- **出处**：[ranxianglei/billion-context](https://github.com/ranxianglei/billion-context)
- **场景备注**：适合超长编程会话；不是「一个 Skill 装完即用」。流量会经过本地代理，敏感代码与客户数据慎用。未安装实测。各客户端细节以 README / `docs/clients.md` 为准。

## 3. Modern Web Guidance

- **🏷️ 向未来**
- **用途**：Chrome、Edge、Firefox 与 MDN 团队共同维护的编程 Agent 技能包：引导 Agent 按当代 Web 平台写法写页面（性能、无障碍、少堆过时 polyfill），也可扫描旧代码找出该升级的地方。汇总称 11 月 10 日发布 1.0。
- **安装 / 使用**（[官方入门文档](https://developer.chrome.com/docs/modern-web-guidance/get-started) / README）：推荐 `npx modern-web-guidance@latest install`（走官方 CLI，可自动更新）。也可：
  - `npx skills add GoogleChrome/modern-web-guidance`
  - Claude Code：`claude plugin marketplace add GoogleChrome/modern-web-guidance`，再 `claude plugin install modern-web-guidance@googlechrome`
  - Codex：`codex plugin marketplace add GoogleChrome/modern-web-guidance`，再 `codex plugin add modern-web-guidance@googlechrome`
  - 安装前可先搜指南：`npx modern-web-guidance@latest search "animate a dialog modal backdrop"`
- **出处**：[GoogleChrome/modern-web-guidance](https://github.com/GoogleChrome/modern-web-guidance) · [Chrome 入门文档](https://developer.chrome.com/docs/modern-web-guidance/get-started)
- **场景备注**：商旅 Web / 管理后台，以及向未来落地页、课件页，减少 Agent 写出过时前端。未安装实测。

## 4. Hill Climb

- **用途**：给编程 Agent 加一道「用分数证明做完了」的关卡：每一步改动只有让锁定的测试或基准分数变好才会被提交，否则回滚；若去改测试 / 检查本身，会被拒绝。需要 **Python 3.9+** 和 git，无额外 Python 包、无服务器、无账号。
- **安装 / 使用**（README）：
  - Claude Code 插件：`/plugin marketplace add Bil0000/Hill-Climb`，再 `/plugin install hill-climb@hill-climb`（插件里的命令是 `/hill-climb:hill-climb`）。
  - 通用（Claude Code / Codex 等会读 `SKILL.md` 的 Agent）：`git clone https://github.com/Bil0000/Hill-Climb.git`，再把 `Hill-Climb/skills/hill-climb` 拷到 `~/.claude/skills/` 或 `~/.codex/skills/`。
  - 用法示例：`/hill-climb make the test suite 2x faster`；大目标会先出示一页计划，等你说 go。Codex 需在提示词里点名该 Skill。
  - 更新：Claude Code 不会自动从该 marketplace 升级，需按 README 执行 `claude plugin marketplace update hill-climb` 等；拷贝安装则 `git pull` 后再拷一次。
- **出处**：[Bil0000/Hill-Climb](https://github.com/Bil0000/Hill-Climb)
- **场景备注**：适合修 bug、补测试、压性能这类能写成检查命令的任务；不能替代人工验收。未安装实测。

## 6. qiaomu-deepseek-api

- **🏷️ 向未来**
- **用途**：向阳乔木把 DeepSeek 官方 API（搜索、读链接、读文件、OCR、转写、TTS 配音、Flash 问答等）打包成 Agent Skill，用自己的 `DEEPSEEK_API_KEY` 在支持 Agent Skills 的工具里一句话调用。需 **Node.js/npm**（安装命令）和 **Python 3.10+**（运行脚本，不必另装 Python 包）。上传或输入的内容会发给 DeepSeek，工具用量可能收费。仓库 11/14 刚发布时汇总提醒还缺乏他人验证，用前最好先看一眼代码。
- **安装 / 使用**（README）：
  - `npx skills add joeseesun/qiaomu-deepseek-api`
  - 在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 申请 Key，通过宿主注入 `DEEPSEEK_API_KEY`；或在 Skill 目录运行 `python3 scripts/deepseek_api.py setup`（不要把 Key 发到聊天里）。
  - 也可以直接跑脚本，例如：`python3 scripts/deepseek_api.py tts --text '你好，欢迎收听。' --voice stella --output demo.wav`
- **出处**：[joeseesun/qiaomu-deepseek-api](https://github.com/joeseesun/qiaomu-deepseek-api)
- **场景备注**：向未来课件转写 / 配音、扫描资料 OCR；商旅侧也可用来做发票识别或语音草稿。作者也提醒 DeepSeek 的语音识别和合成不一定是最强，有更好替代时可以不用。未安装实测。

- **出处**：[anthropics/skills 中的 pptx](https://github.com/anthropics/skills/tree/main/skills/pptx) · [来源帖](https://x.com/okapi_fukugyo/status/2121777911409877374)
