Skill 周推荐 · 2026年10月27日（10月25日–27日）

说明：汇集本周「X 创意想法每日汇总」里「值得试的 AI Skill」条目，便于收藏与安装。安装命令以汇总原文为准；链接指向官方仓库或介绍页。带「🏷️ 向未来」标签的条目适合招生物料、课件、落地页、宣传片等 K-12 AI 教培场景。

本周从 10 月 25–27 日三晚汇总里攒下四个前端 / 多媒体向 Skill：两个偏页面质感，一个偏架构图，一个把视频与配乐交代理手。

1. Impeccable

  • 🏷️ 向未来
  • 用途：前端设计 Skill，专门审、改 AI 生成的 UI——布局、字体、对比度与无障碍（a11y），把「一眼 AI」的页面拉回可用、好看。
  • 安装 / 使用：在项目根目录执行 `npx impeccable install`，再跑 `/impeccable init`；Codex 用户需在 `/hooks` 里批准项目 hook。
  • 出处：pbakaus/impeccable · Perplexity Computer 限时免费提及
  • 场景备注：产品内部工具与营销页；向未来落地页 / 课件页质感；商旅侧同类页面同样适用。另：Perplexity 将 `/impeccable` 放入 Computer，免费试用至 10 月 31 日。

2. diagram-design

  • 🏷️ 向未来
  • 用途：杂志风架构图 / 流程图 Skill，支持 40+ 图种，输出自包含 HTML+SVG，可套品牌色；仓库约 61k stars。
  • 安装 / 使用：Cursor：`npx skills add cathrynlavery/diagram-design`。Codex：先 `codex plugin marketplace add cathrynlavery/diagram-design`，再 `codex plugin add diagram-design@diagram-design`。
  • 出处：cathrynlavery/diagram-design
  • 场景备注：技术方案、向未来课件与产品架构图、高管 deck。

3. Hallmark

  • 🏷️ 向未来
  • 用途：Together AI 出品的前端设计 Skill，专治「AI 脸」；可在真实浏览器里检查，并能审改 / 重做页面；约 37k stars，向阳乔木推荐。
  • 安装 / 使用：`npx skills add nutlope/hallmark -g`；Cursor 用 `/hallmark`，Codex 用 `$hallmark`。
  • 出处：Nutlope/hallmark
  • 场景备注：官网、落地页、向未来招生 / 产品介绍页。

4. Renoise MCP

  • 🏷️ 向未来
  • 用途：给 Agent 接上视频 / 图像 / 音乐与剪辑能力；向阳乔木反馈 Codex 出片更少「AI 味」。按 credits 计费。
  • 安装 / 使用：Codex：`codex plugin marketplace add renoise-ai/renoise-plugins-official`，再安装 renoise 插件；其他 MCP 客户端可添加 `https://renoise.ai/api/public/mcp`。
  • 出处：Renoise MCP
  • 场景备注：向未来课程宣传片、商旅产品演示片。
