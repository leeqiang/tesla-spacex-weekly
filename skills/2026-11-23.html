1. OpenCodeReview（代码审查 CLI / Skill）

  • 用途：阿里开源的 AI 代码审查工具：读取 Git diff（也可用 `ocr scan` 扫整文件），给出带行号的意见。可用自带审查流水线（需单独配置模型服务），或「委托模式」让当前编程 Agent 按它的选文件、规则和报告格式来审。需要 Git >= 2.41；支持 Windows / macOS / Linux。许可证为 Apache-2.0。不能替代测试和人工验收。
  • 安装 / 使用（README）：
  • 推荐在要审查的项目里执行：`npx skills add alibaba/open-code-review`，按安装器选择 Skill 和宿主。没有单独的 OCR 模型密钥时，README 建议先用委托模式（`open-code-review-delegate`）。
  • CLI：`npm install -g @alibaba-group/open-code-review`，之后可用 `ocr`。原生模式需先 `ocr config provider` 和 `ocr config model`。委托模式示例：`ocr delegate preview`。
  • 其他安装方式（安装脚本、Release 二进制、从源码构建）以及 Claude Code / Codex 插件命令，见 官方安装文档 和仓库 `plugins/open-code-review/README.md`。
  • 出处：alibaba/open-code-review · 官网文档 · 来源帖
  • 场景备注：适合评估是否加入 3C / Codex 的交付审查。汇总 11/15 首次推荐。未安装实测。审查意见会发给所配置的模型服务，敏感代码慎用。

2. Filmera MCP / Skill

  • 🏷️ 向未来
  • 用途：把分镜、生成镜头、特效、时间线和导出做成 Agent 可调用的 MCP 工具，并配有规划镜头、写提示词的 Skill。官方文档写明支持 Seedance 2.5 等模型（最高到 4K 的说法以当前模型目录为准）。生成、重拍、配音和放大会消耗 Filmera 积分；创建和整理节点不收费。11/15 汇总首次提到，11/20 补充了 Skill、积分和「先用更快的模型试提示词」的用法，属同一条目的实质补充，本期只收录一次。
  • 安装 / 使用（官方 MCP 文档 / SKILL.md）：
  • MCP 端点：`https://www.filmera.ai/api/mcp`（Streamable HTTP）。用连接器 / 远程 MCP 接入后，以 OAuth 登录；API Key 会被 MCP 拒绝，不要在配置里加 `Authorization` 头。REST 自动化仍可用账号里的 API Key。
  • Claude Code 插件：`/plugin marketplace add filmera-ai/filmera-plugins`，再 `/plugin install filmera@filmera`。也可只加服务器：`claude mcp add --transport http filmera https://www.filmera.ai/api/mcp`。首次调用会打开浏览器登录，之后可用 `/mcp` 重新登录。
  • Cursor：可在 Filmera 工作室里用「Add to Cursor」；或把 `{"mcpServers":{"filmera":{"url":"https://www.filmera.ai/api/mcp"}}}` 写入 `~/.cursor/mcp.json`（不要加 headers）。插件仓库写明 Cursor Marketplace 条目仍在审核中。
  • 其他支持 Streamable HTTP 和 OAuth 2.1 的客户端也可接入；只能发固定 API Key 头的客户端连不了 MCP，可改用 REST。Claude、ChatGPT、Gemini、Grok 的点击接入步骤见官方文档。
  • 默认会在对话里先报价、等你同意再生成，但官方写明这不是硬锁（依赖 Agent 如实转述）；硬上限需在设置里给该 Agent 加消费封顶。
  • 出处：Filmera MCP 文档 · SKILL.md · filmera-ai/filmera-plugins · 11/20 来源帖
  • 场景备注：向未来课程片、产品演示可先低成本试镜头再出成片。素材和生成会经过 Filmera 云端，注意授权和积分消耗。未安装实测。

3. Next Token Skill

  • 🏷️ 向未来
  • 用途：让 Agent 检索中文播客「Next Token｜词元之外」的逐字稿和文章，回答时引用主理人观点，并附 B 站 / YouTube 时间戳链接。需要 Python 3，只用标准库，不必另装依赖，也不要 API Key。代码为 Apache-2.0；节目逐字稿、文章和品牌不在开源许可内，由脚本运行时从官网同步到本机缓存（默认 `~/.cache/nexttoken/`）。
  • 安装 / 使用（README）：
  • Claude Code：先 `git clone https://github.com/next-token-tv/next-token-skill.git next-token-skill`，再 `mkdir -p ~/.claude/skills && ln -s "$(pwd)/next-token-skill/next-token" ~/.claude/skills/next-token`。更新在仓库目录执行 `git pull`。
  • 其他会读 `SKILL.md`、能跑本地命令的 Agent：把 `next-token` 目录放到对应 skills 目录。不能跑本地脚本的网页版助手用不了。
  • 也可直接跑脚本，例如：`python3 next-token/scripts/nexttoken.py search 一人公司`。
  • 出处：next-token-tv/next-token-skill · 来源帖
  • 场景备注：技能本身只服务这一档节目。更值得向未来借鉴的是「回答带出处、并能跳到视频时间点」的组织方式；若拿自己的课程做同类检索，需要另做内容库，并确认版权和出镜授权。未安装实测。

4. Superpowers

  • 用途：一套给编程 Agent 用的软件开发方法与技能包：先澄清需求和设计，再写可执行计划，强调测试驱动，并按任务拆给子 Agent。技能会自动触发。许可证为 MIT。官方支持多种宿主，需按所用工具分别安装。
  • 安装 / 使用（README）：
  • Claude Code（官方市场）：`/plugin install superpowers@claude-plugins-official`。也可先 `/plugin marketplace add obra/superpowers-marketplace`，再 `/plugin install superpowers@superpowers-marketplace`。
  • Cursor：在 Agent 对话里执行 `/add-plugin superpowers`，或在插件市场搜索 superpowers。
  • Codex：在官方插件市场安装；CLI 里用 `/plugins` 搜索 Superpowers 后选择 Install Plugin。
  • 其他宿主（Antigravity、Gemini CLI、Copilot CLI 等）命令见 README。README 写明更新方式因宿主而异，有的会自动更新。
  • 可选遥测：头脑风暴可视化里的 Logo 默认从作者网站加载以统计版本，不含项目或提示词内容；可用 `SUPERPOWERS_DISABLE_TELEMETRY` 关闭，并尊重 Claude Code 的遥测关闭项。
  • 出处：obra/superpowers
  • 场景备注：可评估与 3C 现有开发规范是否重复，不必整包当作全新流程。未安装实测。

5. Marketing Skills

  • 🏷️ 向未来
  • 用途：面向营销任务的 Agent 技能集，覆盖转化优化、文案、SEO、分析和增长实验，适用于 Claude Code、Codex、Cursor 等支持 Agent Skills 的工具。仓库为 MIT。装上不等于就能获客；涉及广告账户或客户数据时，仍应先用公开或脱敏材料，并人工审核。
  • 安装 / 使用（README；推荐 CLI）：
  • `npx skills add coreyhaines31/marketingskills`（可加 `--skill cro copywriting` 只装一部分，或 `--list` 查看列表）。若在 Agent 会话内安装，CLI 可能只装到 `.agents/skills/`，Claude Code 读不到，需显式加上 `-a claude-code`。
  • Claude Code 插件：`/plugin marketplace add coreyhaines31/marketingskills`，再 `/plugin install marketing-skills`；非交互环境可用 `claude plugin marketplace add coreyhaines31/marketingskills` 和 `claude plugin install marketing-skills@marketingskills`。
  • Codex：`codex plugin marketplace add coreyhaines31/marketingskills`，再在会话里用 `/plugins` 安装 marketing-skills。
  • 出处：coreyhaines31/marketingskills · marketing-skills.com
  • 场景备注：可用来准备向未来招生物料或落地页的增长实验草稿。仓库含可选的第三方工具对接，凭证不要提交到 Git。未安装实测。

6. Boring Marketing Skills

  • 🏷️ 向未来
  • 用途：另一套免费营销技能包（README 写明 32 个技能），覆盖调研、定位、文案、落地页、SEO、AI 搜索、广告、邮件和内容，并有本地商家相关技能。面向 Claude Code、Codex、Cursor 等；README 称技能不依赖付费工具。许可证为 MIT。与上一则不是同一个仓库。
  • 安装 / 使用（README）：
  • 通用：`npx skills add boringmarketer/boring-marketing-skills`
  • Claude Code 插件：`/plugin marketplace add boringmarketer/boring-marketing-skills`，再 `/plugin install boring-marketing@boring-marketing-skills`
  • 装好后先运行 `/start-here` 并指定业务；它会读取网站和评论、写出其他技能共用的品牌文件，再建议下一步。
  • 出处：boringmarketer/boring-marketing-skills
  • 场景备注：汇总建议拿「向未来」的一页介绍材料做小范围测试。产出仍需人工改。未安装实测。

7. UI SDK（界面行为库，附带 Skill）

  • 用途：Vercel Labs 的界面行为库：把键盘操作、焦点、选择、关闭、弹层、拖拽和所需 ARIA 放在 `@ui-sdk/core`，并有 React / Vue / Svelte / Solid / Web Components 适配。当前 README 写明处于 beta，受 Vercel beta 条款 约束，API 和行为在正式版前可能变化。许可证为 Apache-2.0。它是前端库，不是装完即用的产品界面。
  • 安装 / 使用（README）：
  • `npm install @ui-sdk/react @ui-sdk/core`（其他框架把 `@ui-sdk/react` 换成 `@ui-sdk/vue`、`@ui-sdk/svelte`、`@ui-sdk/solid` 或 `@ui-sdk/web`）。
  • 再给 Agent 装技能：`npx skills@latest add vercel-labs/ui --skill ui-sdk`
  • 出处：vercel-labs/ui · 文档
  • 场景备注：可作为 3C 前端交互的研究候选，不能仅凭介绍认定已经兼容或更稳定。未安装实测。

8. Punchcutter（字体工坊 Skill / MCP）

  • 用途：在 Claude、ChatGPT、Codex 等里按描述或手写照片生成可安装的英文字体家族（可变字体、字距、OpenType，并附 Studio 预览页）。需要 Python 3.10+。代码为 MIT；你做出的字体版权归你，可自选授权。
  • 安装 / 使用（README）：
  • Claude Code 插件：`/plugin marketplace add byrishi/punchcutter`，再 `/plugin install punchcutter@punchcutter`。或 `npx skills add byrishi/punchcutter`。随后需 `pip install -r ~/.claude/skills/punchcutter/scripts/requirements.txt`。
  • Codex：`npx skills add byrishi/punchcutter --agent codex`，或 `codex mcp add punchcutter -- punchcutter mcp`。
  • MCP 客户端：`pip install "punchcutter[mcp] @ git+https://github.com/byrishi/punchcutter"`，再在 MCP 配置里加入 `"command": "punchcutter", "args": ["mcp"]`。
  • 出处：byrishi/punchcutter · 文档
  • 场景备注：README 写明目前只支持拉丁字母（Basic Latin、Latin-1、Latin Extended-A），暂无中文，对向未来中文课件的直接价值有限，更适合英文品牌实验。默认有匿名用量统计，可用 `punchcutter telemetry off` 或 `DO_NOT_TRACK=1` 关闭。未安装实测。不要用来仿制商业字体或商标。

9. baoyu-skills（及《图解 Skill》配套资源）

  • 🏷️ 向未来
  • 用途：宝玉分享的开源技能集，面向 Claude Code、Codex 等，覆盖写作、配图、会议纪要、排版和日常重复工作。仓库建议按需只装会用到的几个，不要一次全装，以免占上下文。需要已安装的 Node.js，并能运行 `npx bun`。根许可证为 MIT（发布到 ClawHub 的单个技能按该平台规则以 MIT-0 分发）。《图解 Skill》的配套资源仓库提供书中模板和说明，安装开源技能集仍以 baoyu-skills 为准。
  • 安装 / 使用（README / 中文 README）：
  • 推荐：`npx skills add jimliu/baoyu-skills`
  • Claude Code 等插件市场：`/plugin marketplace add JimLiu/baoyu-skills`，再 `/plugin install baoyu-skills@baoyu-skills`
  • 也可只把需要的技能目录拷到项目的 `.agents/skills/`。更新可在插件市场里执行 Update marketplace。
  • 出处：JimLiu/baoyu-skills · JimLiu/Illustrated-Agent-Skills
  • 场景备注：和在 3C 里沉淀可复用流程是同一方向。部分技能会调用外部模型或平台 API，密钥放在 `~/.baoyu-skills/.env` 或项目级 `.env`，不要提交到 Git，也不要把 Key 发到聊天里。未安装实测。

10. T3 Code（控制面应用，不是 Skill）

  • 用途：开源的编程 Agent 控制面：在同一个界面里调度本机已登录的 Claude Code、Codex、Cursor、OpenCode、Grok Build、Antigravity 等（以及兼容 ACP 的 Agent），使用你已有的订阅，不转售 token。有桌面端、网页和手机端，也可远程连接。许可证为 MIT。官网当前最新发布包为 v0.1.11（以 Releases 为准）。
  • 安装 / 使用（README / 下载页）：
  • 桌面应用：从 t3.codes/download 下载 macOS / Windows / Linux 安装包。也可 `brew install --cask t3-code`（macOS）、`winget install T3Tools.T3Code`（Windows），Debian / Ubuntu 可用 Releases 里的 `.deb`。
  • 命令行：`curl -fsSL https://t3.codes/install.sh | sh`（Windows PowerShell：`irm https://t3.codes/install.ps1 | iex`）。想先试用可 `npx t3@latest`。
  • 手机：App Store / Google Play，再按文档把手机连到本机。
  • 使用前需至少有一个已安装并登录的 Agent（例如 `claude auth login` 或 `codex login`）。各 Agent 的接入步骤见官方安装文档。
  • 出处：t3.codes · pingdotgg/t3code
  • 场景备注：适合同时使用多个编程助手时做统一入口。汇总提到需留意各 Agent 的账号政策，这些说法未经核对，用前请先看官网和相应条款。未安装实测。

11. Perplexity 官方 skill.md

  • 用途：Perplexity 把 Agent API、Search API，以及 Context、Monitor、Orchestrator 等用法写成一份技能说明，供 Agent 在读网页、监测页面变化或按任务选模型时调用。不是一个带安装器的 GitHub 技能包。调用走官方 API，需要 `PERPLEXITY_API_KEY`，用量可能收费。
  • 安装 / 使用（官方 skill.md）：把该说明交给支持 Agent Skills 或能读取远程文档的宿主使用，并在环境变量中配置 `PERPLEXITY_API_KEY`（不要写进代码或发到聊天里）。具体接入、定价和限制以 Perplexity 文档 为准。本期未在官方 skill.md 中看到类似 `npx skills add` 的安装命令，故不编造。
  • 出处：docs.perplexity.ai/skill.md
  • 场景备注：商旅政策、公开供应商页面或竞品更新日志，可考虑先做监测和材料整理；不能替代实时机票酒店库存接口。Agent 读外部网页前仍应防范提示注入。未接入实测。

12. Open Artifact（原 baoyu-design；实质更新）

  • 🏷️ 向未来
  • 用途：宝玉把原来的 baoyu-design 重建为开源、不绑定特定模型的本地工件编辑器：让 Cursor、Codex、Claude Code 等在本机生成可打开、编辑、批注和导出的幻灯片、UI 设计、设计系统、白板、表格、数据看板、文档和短片。旧地址 JimLiu/baoyu-design 会 301 到本仓库。产物是普通文件夹，由本机守护进程打开编辑页，再把批注送回 Agent 会话。官方强调默认在本机运行，不强制账号、也不绑定某一家模型。许可证为 Apache-2.0。这与早期「一条 `npx skills add JimLiu/baoyu-design` 即用」的安装方式不同，属于实质更新，故再次收录。
  • 安装 / 使用（README / 插件说明；需 Node.js 22.18+）：
  • 推荐：从 Releases 下载 `open-artifact-plugins.zip`（核验时最新为 v0.13.0），解压到固定目录。
  • Claude Code：`claude plugin marketplace add "/path/to/open-artifact-plugins"`，再 `claude plugin install open-artifact@open-artifact`。
  • Codex：`codex plugin marketplace add "/path/to/open-artifact-plugins"`，再在 `/plugins` 里安装 Open Artifact，或 `codex plugin add open-artifact@open-artifact`。钩子需在 `/hooks` 中批准后才会运行。
  • Cursor：把解压后的 `cursor/` 目录拷到 `~/.cursor/plugins/local/open-artifact`，再执行 Developer: Reload Window。
  • 其他宿主（Copilot、Antigravity、ChatGPT、DeepSeek Harness 等）见各插件目录说明。装好后可试：`/open-artifact slides a 6-slide pitch for this repo`。
  • 出处：JimLiu/open-artifact · Releases
  • 场景备注：向未来课件、教学短视频、3C 或产品演示都可以先在编辑器里做，再手工改。可选的自建托管会把工件发到你的服务器，需单独按文档配置。未安装实测。

13. 补充候选（非当晚例行汇总）：assistant-ui

  • 用途：开源的 TypeScript / React AI 对话组件库，不只是聊天气泡：可把工具名称、参数、运行状态做成卡片，收集允许或拒绝，并提供流式输出、代码高亮、附件、停止和重试等。许可证为 MIT，可自建使用，不强制购买其云服务。它只负责界面和交互状态，不能替代任务队列、权限校验和失败恢复；界面上的审批按钮不等于安全授权，后端仍须验证具体操作并防止审批被重复使用。
  • 安装 / 使用（README）：
  • 新项目：`npx assistant-ui@latest create`；已有项目：`npx assistant-ui@latest init`。
  • 或直接：`npm install @assistant-ui/react @assistant-ui/ai-sdk ai`。文档和示例见 assistant-ui.com/docs。
  • 出处：assistant-ui/assistant-ui · 来源帖
  • 场景备注：比上期已写的官方 pptx Skill 更贴近 3C 对话区升级，适合先试接一个「任务详情 / 对话区」，不要整站重写。本次只核对了官方文档，尚未检查 3C 前端技术栈或实测接入。
